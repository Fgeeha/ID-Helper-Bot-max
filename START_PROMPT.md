## Задача

Реализуй Telegram-подобного бота для мессенджера **MAX** на библиотеке
`maxapi`, который показывает идентификаторы. Инфраструктура (Dockerfile,
docker-compose local/prod, Makefile, pyproject с uv, .env.example) уже готова —
её не трогай без необходимости. Тебе нужно написать **код бота** в `src/bot/`.

## Что должен уметь бот

1. **Приветствие** при `@router.bot_started()` — короткое описание + inline-меню.
2. **Мой ID** — команда `/myid` и кнопка: `user_id`, имя, `@username`, ссылка
   `max://user/{id}`. Данные берём из `event.message.sender`.
3. **ID чата** — команда `/chatid` и кнопка: `chat_id` и тип чата
   (`event.message.recipient`).
4. **Пересланное сообщение** — если у входящего сообщения есть `link`
   (`LinkedMessage`), показать ID автора (`link.sender.user_id`) и `mid`.
5. **Контакт** — если во вложениях есть `type == "contact"`, взять
   `payload.max_info` (это `User`) и показать `user_id` этого человека.
6. **Медиа** (фото/видео/файл) — показать тип и `file_id`, если он есть.
7. **Кнопка «Скопировать ID»** через `ClipboardButton` (payload = значение ID).
8. Если полезного ID в сообщении нет — вежливая подсказка, что можно прислать.

## Требования к реализации

- Src-layout, пакет `bot`, запуск `python -m bot`. Точка входа собирает
  `Dispatcher`, подключает роутеры через `include_routers`, перед polling
  вызывает `await bot.delete_webhook()`.
- Раздели на модули: `handlers/ids.py` (логика ID), `handlers/callbacks.py`
  (нажатия кнопок), `keyboards/menus.py` (клавиатуры), `config.py` (чтение
  окружения: `BOT_TOKEN` обязателен, `LOG_LEVEL`, `ADMIN_IDS`).
- **Важно про порядок хендлеров:** catch-all `@router.message_created()`
  (без фильтра) регистрируй последним, чтобы он не перехватывал команды.
- Весь вывод — с `parse_mode=ParseMode.HTML` (используй `<b>`, `<code>`).
- Callback-нажатия обязательно подтверждай (`event.edit(...)` или
  `event.answer()`), иначе кнопка зависнет.
- Добавь в `__main__` функцию `cli()` — синхронную обёртку над
  `asyncio.run(main())` (на неё ссылается `project.scripts` в pyproject).
- Тексты для пользователя — на русском, код и имена — на английском.

## Не полагайся на память по `maxapi`

Прежде чем использовать незнакомое поле или метод, проверь его в реальной
библиотеке, например:
`uv run python -c "from maxapi.types import User; print(User.model_fields.keys())"`

## Definition of Done

- `make install` отрабатывает, `uv.lock` создан и закоммичен.
- Есть минимальные тесты в `tests/` на форматтеры ID (без сети): проверка
  вывода для обычного пользователя и для контакта. `make test` зелёный.
- `make lint` зелёный.
- `make run` стартует бота (падение только на пустом `BOT_TOKEN` — это ок).
- `make build` собирает Docker-образ без ошибок.
- Обнови `.env.example` и `README.md`, если добавишь переменные/команды.

Начни с чтения `CLAUDE.md` и осмотра дерева репозитория, затем предложи
короткий план (какие файлы создашь), и после него приступай.
