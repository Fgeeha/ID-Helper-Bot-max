# ID Helper Bot 🆔

MAX-бот, который показывает идентификаторы: твой `user_id`, `chat_id`, ID
автора пересланного сообщения и ID человека, которым поделились как контактом.

## Что умеет

| Действие | Что показывает |
|----------|----------------|
| `/start`, `/help` | Приветствие и меню |
| `/myid` или кнопка «Мой ID» | `user_id`, имя, `@username`, ссылка `max://user/{id}` |
| `/chatid` или кнопка «ID чата» | `chat_id` и тип чата (диалог / группа / канал) |
| Переслать сообщение | `user_id` автора, `chat_id` источника, `mid` сообщения |
| Прислать контакт | `user_id` человека из контакта |
| Прислать фото, видео, файл | Тип вложения и идентификатор медиа |

К каждому ответу прикладывается кнопка «📋 Скопировать ID».

## Стек

- Python ≥ 3.12, пакетный менеджер **uv**
- Библиотека бота — `maxapi` (long polling)
- Docker (multi-stage) + docker compose (local / prod)
- Makefile для рутинных команд

## Быстрый старт

```bash
# 1. окружение
cp .env.example .env
# впиши BOT_TOKEN (получи у @MasterBot: /create, ник должен кончаться на _bot)

# 2. зависимости
make install

# 3. запуск без Docker
make run
```

## Docker

```bash
make up          # локальный стек (detached)
make watch       # локальный стек с авто-перезапуском на изменение кода
make logs        # логи
make down        # остановить

make prod-up     # прод-стек
make prod-logs
make prod-down
```

## Переменные окружения

| Переменная | Обязательна | Назначение |
|------------|-------------|------------|
| `BOT_TOKEN` | да | Токен бота от @MasterBot |
| `LOG_LEVEL` | нет | Уровень логов, по умолчанию `INFO` |
| `ADMIN_IDS` | нет | ID админов через запятую (для служебных команд) |

Шаблон — в [`.env.example`](./.env.example). Сам `.env` в `.gitignore`.

## Структура

```
src/bot/
├── __main__.py        # точка входа: Dispatcher, delete_webhook, polling
├── config.py          # чтение окружения
├── formatters.py      # чистые функции форматирования (покрыты тестами)
├── handlers/
│   ├── ids.py         # команды и разбор входящих сообщений
│   └── callbacks.py   # нажатия inline-кнопок
└── keyboards/
    └── menus.py       # inline-клавиатуры
```

Роутеры подключаются в порядке `commands → callbacks → fallback`: catch-all
обработчик живёт в отдельном роутере и идёт последним, иначе он перехватил бы
команды.

## Разработка

```bash
make check   # ruff check + pytest
make fmt     # ruff format
make lock    # пересобрать uv.lock
```

Полный список команд — `make help`. Правила работы с репозиторием и сверенные
факты про MAX API лежат в [`CLAUDE.md`](./CLAUDE.md).

## Заметки

- В групповых чатах боту нужны права администратора, иначе события не приходят.
- Публикация ботов в MAX (с августа 2025) доступна только юрлицам РФ;
  на локальную разработку это не влияет.
